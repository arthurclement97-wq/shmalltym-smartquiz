# Smart Study Buddy

Build a React-based AI Quiz Generator called Smart Quiz.

The app should allow students to upload a PDF, image, or paste text. Use a secure backend function to send the extracted content to the OpenAI API using the OPENAI_API_KEY environment secret. Never expose the API key in frontend code.

Generate quizzes based strictly on the uploaded study material.

Features:

Upload PDF or image

Choose number of questions

Choose Multiple Choice or True/False

Optional timer

Display one question at a time

Four answer options for MCQ

Mark correct answers green and wrong answers red

Show the correct answer when the user is wrong

Add an “Explain Answer” button powered by AI

Show progress: Question 3 of 20

Calculate final score and percentage

Show results summary at the end

Allow the user to restart or generate another quiz

Design should be modern, clean, responsive, and student-friendly.

Use React and Tailwind CSS.
